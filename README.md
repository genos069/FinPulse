# FinPulse - Financial Puls

Personal Finance Management Application.

## Tech Stack

### Client

* React Native
* TypeScript

### Server

* Java
* Spring Boot
* Maven
* PostgreSQL/ MongoDB

## Project Structure

```text
FinPulse/
├── client/    # React Native mobile application
├── server/    # Spring Boot REST API
└── README.md
```

## Features

* Expense & Income Tracking
* Financial Goals
* Bank & Account Management
* Money Health Score
* Transaction Categorization
* Ask Your Money
* Salary Rebalancer
* Subscription & Bill Radar
* Investment Learning
* What-If Simulator
* Festival Forecast
* Emergency Fund
* Micro Lessons
* Split & Settle
* Reports & Export
